# QWIKIT

Calgary, Alberta software company. We build:

- **QWIKIT Jobs**, a job-search workspace that gives QWIKIT's own score of how eight hiring systems would read your resume, and drafts text that stays true to your experience. Pre-order and details: https://jobs.qwikit.co
- **QWIKIT Plans**, floor-plan measurement software. Waitlist and details: https://plans.qwikit.co

Company site: https://qwikit.co
